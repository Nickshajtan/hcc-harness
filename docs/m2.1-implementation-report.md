# M2.1 implementation report

Baseline: `main` at `3307b38`. Scope: npm CLI exposure and filesystem diagnostics.

The private package exposes `arch` directly through `dist/cli.js`'s existing Node
shebang. There is no installer, second CLI, production dependency, manifest change,
or publication fallback. Core, event bus, middleware and native process execution
implementations are unchanged. Existing reserved-name validation excludes `arch`;
regression tests exercise it through the installed command.

Npm-link tests use a temporary prefix/home/cache and target project. They compare
installed and direct help, exercise deterministic lifecycle commands, preserve
argument/stdin/exit behavior, prove unlink leaves project configuration and
absolute-path launchers usable, and test POSIX signal forwarding. Existing native
Windows console tests continue to validate execution signals. All 13 real-terminal
wizard scenarios now use the npm-linked executable, including Windows `.cmd`
launching and Ctrl+C. Integration tests also exercise npm's PowerShell shim.

Hard-link failures include the target, OS error code, required capability and
filesystem guidance. Deterministic tests inject ENOTSUP, EOPNOTSUPP, ENOSYS and
EPERM, verify byte-for-byte preservation and no fallback, cover failure after
journal publication and recovery, and show ordinary init/deinit call no hard links.
Existing collision, manifest replacement and real subprocess interruption tests
remain in the complete suite.

## Limits

No real exFAT volume is required or tested. Capability failures are deterministic
injections; actual supported publication is exercised on each runner's temporary
filesystem. Windows ARM64, other Node major versions, every terminal emulator,
network mounts, and manual AI-tool TUIs are not validated here. Npm's standard
shell/shim quoting and PowerShell execution-policy rules apply; direct Node
invocation remains available. Parent-shell mise activation is not proven by CLI
installation or project initialization. Recovery retains M2's documented limits:
no atomic route-set switch or power-loss durability guarantee.
